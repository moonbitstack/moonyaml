examples · three programs

Nothing here is a mock-up.

Three programs in src/examples/, each runnable with one command, and the output each of them prints — captured from a real run, not written by hand. If a number in this page were wrong, the program next to it would disagree.

Read the guide Start with the tour

01 · the tour

Everything it reads, in one file.

A configuration file of the shape one is actually written in: block collections, a literal scalar that keeps its line breaks, an anchor reused further down, a flow sequence. Then the core schema deciding what an unquoted scalar is, a stream of two documents, and four refusals with the position each one is at.

moon run src/examples/tour

Two things to notice. dumps invented the anchor name &a0, because a value has no anchor names — the Json tree only knows that upload and limits are the same object. And the last line is the "billion laughs" cut short: four lines of aliases that would expand to sixteen nodes, refused the moment the count passes a budget of eight, with the count and the limit in the message.

02 · the versions

One document, read five ways.

yes is a boolean in 1.1 and a string in 1.2. 014 is octal twelve in 1.1 and decimal fourteen in 1.2. 12:30 is a sexagesimal only in 1.1. The same file, five readings, and not one of them is a bug:

moon run src/examples/versions

The last three lines are any, which is the only reader here that looks at the document to decide: %YAML 1.1 at the top makes yes a boolean, %YAML 1.2 makes it a string, and no directive at all means 1.2.2.

03 · the document

Read it, write it, and get the file back.

parse gives a tree that keeps what the file said — the comment above the document, the comment beside the image line, the anchor, the alias standing in for its value, the flow style of ports, the literal block scalar. emit writes it back and the program compares the two strings:

moon run src/examples/document

"yes, byte for byte" is printed only when emit(parse(src)) == src. Below it, the same document through to_json — which is where the alias stops being an alias and the merge key is folded in — then a tree built from a value at indent=4, then the writer in flow style.

04 · run them

Three commands.

# everything it reads, in one file
moon run src/examples/tour

# one document, read five ways
moon run src/examples/versions

# the document model, and a round trip
moon run src/examples/document
